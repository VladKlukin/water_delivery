# Сервис доставки воды

Веб-приложение для оформления заказов на доставку воды. Клиент заполняет
форму, выбирает дату и доступный интервал доставки. Сотрудник может
просматривать и отменять заказы.

## Задание

Проект выполнен по тестовому заданию
[«Сервис доставки воды»](https://github.com/Hexlet/ru-test-assignments/blob/main/backend/anmedio/backend-task.md).

## Возможности

- Оформление заказа через веб-форму.
- Просмотр списка заказов.
- Отмена заказа.
- Проверка данных при создании заказа.
- Получение доступных интервалов по выбранной дате.
- Хранение заказов в PostgreSQL.

## Интервалы доставки

| День | Доступное время |
|---|---|
| Будни | 10:00-11:00, 12:00-13:00, 15:00-16:00 |
| Выходные | 12:00-13:00, 15:00-16:00 |

## Запуск проекта

Для запуска нужны Git и запущенный Docker Desktop.

### 1. Клонирование репозитория

```powershell
git clone https://github.com/VladKlukin/water_delivery.git
cd water_delivery
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта и добавьте в него:

```text
POSTGRES_PASSWORD=your_password
```

Можно взять за основу файл `.env.example`. Для простого локального запуска
используйте пароль из латинских букв и цифр.

### 3. Запуск контейнеров

```powershell
docker compose up --build -d
```

### 4. Создание таблиц

После запуска контейнеров выполните:

```powershell
docker compose exec app python -m app.init_db
```

### 5. Открытие приложения

- Форма заказа: http://127.0.0.1:8000/
- Список заказов: http://127.0.0.1:8000/orders
- Документация API: http://127.0.0.1:8000/docs

## API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/order` | Создать заказ |
| `GET` | `/order/list` | Получить список заказов |
| `GET` | `/delivery-slots` | Получить интервалы для даты |
| `PATCH` | `/order/{order_id}/cancel` | Отменить заказ |

Примеры запросов можно посмотреть и выполнить в документации `/docs`.

## Проверка

Работа приложения проверена вручную: созданы и просмотрены заказы,
проверены отмена заказа и выбор интервалов в будни и выходные.

С помощью pytest написаны тесты для интервалов доставки, создания
и отмены заказа.

## Что не сделано

Полноценный интерфейс с подробным дизайном не разрабатывался.
Для оформления заказа используется простая HTML-форма.

Страница списка заказов и API доступны без авторизации. Приложение
предназначено для локального запуска.

## Остановка

```powershell
docker compose down
```

Заказы остаются в Docker volume и сохраняются между запусками.
